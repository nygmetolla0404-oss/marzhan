# marzhan — Цифрлы Қазақстан: 3D виртуалды әлем

Информатика пәніне арналған интерактивті 3D әлем: интернет және жасанды интеллект Қазақстанда.

- 11 станция: Alem.AI, alem.cloud суперкомпьютері (NVIDIA), Astana Hub (Higgsfield), Интернет қақпасы, Байқоңыр, Майнинг фермасы, Қазақша ЖИ, Ақылды қала, Ақылды егістік, Болашақ мамандықтары, Бәйтерек.
- Әр станцияның ішіне кіріп, 3D залдағы экспонаттарды зерттеуге болады.
- Қазақ тіліндегі аудиогид.

**Ашу:** `index.html` файлын браузерде ашыңыз немесе GitHub Pages сілтемесіне өтіңіз.

Басқару: W A S D — жүру, Space — ұшу, E — ішіне кіру, тінтуір — айналаға қарау.

Автор: Шайжанова Маржанкул Бахтияровна, информатика пәні мұғалімі, Астана қаласы, Кемел Ақышев атындағы №69 мектеп-гимназия.
«Педагогикалық идеялар фестивалі» республикалық конкурсы.
